Get a free key at aistudio.google.com. The key is stored only in this browser. With Gemini, the transcribed English text (never your video or audio) is sent to Google for translation.
Get a free key at console.groq.com/keys (no credit card needed). The key is stored only in this browser. With the Groq cloud model, the extracted audio track is sent to Groq for transcription — nothing to download, and the free tier is plenty for personal use.
Cloudflare’s API cannot be called straight from a web page (it blocks cross-origin browser requests), so this option talks to a tiny Worker on your own free Cloudflare account, which runs @cf/openai/whisper-large-v3-turbo for you. No API token is needed in this browser — it stays on Cloudflare’s side. The free Workers plan includes 10,000 neurons per day (roughly 3 hours of audio) and resets at 00:00 UTC. Only the extracted audio track — never the video — is sent to your Worker.
One-time setup (about 3 minutes)
  1. Open the Cloudflare dashboard → Compute (Workers) → Create → Start with Hello World, give it any name, and deploy it.
  2. Click Edit code, delete what is there, paste the code below, and press Deploy.
  3. Go to the Worker’s Settings → Bindings → Add binding → Workers AI, and set the variable name to exactly AI. Deploy again.
  4. Optional but recommended: in Settings → Variables and Secrets, add a secret named APP_SECRET with any password, then type that same password in the field above. This stops strangers from using your free quota.
  5. Copy the Worker’s URL (it looks like https://my-subtitles.your-name.workers.dev) into the field above.
// Cloudflare Worker: runs Whisper for the subtitle app and allows browser calls.
export default {
  async fetch(request, env) {
    const cors = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "POST, OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type, X-App-Secret",
      "Access-Control-Max-Age": "86400",
    };
    const json = (body, status = 200) =>
      new Response(JSON.stringify(body), { status, headers: { ...cors, "Content-Type": "application/json" } });
    if (request.method === "OPTIONS") return new Response(null, { headers: cors });
    if (request.method !== "POST") return json({ success: false, errors: [{ message: "Use POST" }] }, 405);
    if (env.APP_SECRET && request.headers.get("X-App-Secret") !== env.APP_SECRET)
      return json({ success: false, errors: [{ message: "Wrong app secret" }] }, 403);
    try {
      const body = await request.json();
      const result = await env.AI.run("@cf/openai/whisper-large-v3-turbo", {
        audio: body.audio,
        task: body.task || "transcribe",
        language: body.language || "en",
      });
      return json({ success: true, result });
    } catch (err) {
      return json({ success: false, errors: [{ message: String(err && err.message || err) }] }, 500);
    }
  },
};
